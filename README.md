# ar_ability_dev

本仓库主要用于开发 AR 眼镜相关应用，包含各个功能应用的完整设计文档以及实现代码。

## 简介

本仓库围绕 AR 眼镜的应用开发，沉淀各功能模块的：

- **设计文档**：各功能应用的方案设计、架构说明与接口定义
- **实现代码**：与设计文档对应的可运行实现

## 目录结构

```
ar_ability_dev/
├── apps/                    # 各功能应用
│   └── <功能应用>/
│       ├── docs/            # 该功能应用的设计文档
│       └── ...              # 该功能应用的实现代码
└── README.md
```
