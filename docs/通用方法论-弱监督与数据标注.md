# 通用方法论：弱监督与数据标注

> 沉淀自「中国象棋教练」项目的真实数据自动标注讨论（2026-10-05）。
> 结论不限于象棋，可迁移到任何「有领域结构 / 需要真实数据标注」的 CV/ML 任务。

---

## 1. 结构先验当监督（用领域规则替代人工标签）

**一句话**：当一个领域有强生成模型（确定性规则 / 物理定律 / 语法），可以把规则本身当 teacher，替代人工标注。

**象棋案例**：象棋有确定性走子规则 → 用「标准开局 + 规则 forward 传播」自动生成每颗棋子的身份标签，无需人工逐张标注。

**迁移**：
- 物理仿真 → 机器人控制（环境给真值）
- 语法规则 → NLP 解析（文法树当监督）
- 几何约束 → 相机标定 / 角点定位（正交、宽高比、交比当监督）

**判断标准**：先问「这个领域能不能由规则/模型**生成真值**」，能的话优先用规则监督，而不是人工标——人工标是最后手段。

---

## 2. 弱监督信号的三层边界（可辨识 ≠ 可分离 ≠ 无盲区）

**一句话**：评估一个弱监督信号够不够用，要分清三层，缺一层都会翻车。

| 层次 | 问题 | 象棋案例 |
| :-- | :-- | :-- |
| ① 理论可辨识性 | 信号在数学上能否区分目标类别（转移函数是否单射） | 7 种走法规则两两不同 → 可辨识 7 类 |
| ② 统计可分离性 | 区分性样本在数据里是否出现足够多次 | 车 vs 炮只靠「隔子吃」，稀有，有效样本远小于原始 |
| ③ 结构性盲区 | 信号是否对某些类别天生无感 | 红车/黑车走法完全相同，运动永远分不出红黑（色盲） |

**迁移**：设计任何弱监督前，**先问「信号的盲区在哪」**——盲区只能用别的信号补（象棋里用外观补颜色），而不是用更多同类数据硬磨。

**关键心法**：三个层次是**递进且独立**的。「样本量足够」能解决 ②，永远解决不了 ③。

---

## 3. 域差是反复出现的失败模式（合成 → 真实）

**一句话**：合成数据训练的模型在真实数据上泛化失败，是反复出现的模式，而且模型置信度会**虚高**——它不会提示你「我错了」。

**象棋案例**：角点模型、棋子分类器连续两次「合成训练 → 真机输出垃圾，置信度却 ≈ 1.0」。

**迁移**：
- 不要指望「更好的合成数据」或「更强的模型」解决域差——那是在错误的方向上堆力气。
- 真正的杠杆是**自动标注真实数据**（用概念 1 的结构先验给真实数据打伪标签再训）。
- 判断模型是否域差失效，不能只看置信度，要看**真实数据上的输出合理性**（象棋里看局面是否合法）。

---

## 4. 先验有无决定问题难度（同一问题两种难度）

**一句话**：同一个视觉问题，有无先验（ROI / 初值 / 几何约束）会让难度差一个数量级。

**象棋案例**：网格线检测，无先验 Hough 误差 110px；有 SAM 框定的 ROI + 单应 H 先验后，变成「warp 投影找峰」的简单活。

**迁移**：工程上先问「我手上**已经有什么先验**能让它变简单」，把「开放检测」降级成「引导精修」：
- 有粗定位 → 就做局部精修，不做全局搜索
- 有几何模型 → 就用模型预测初值，再小范围修正
- 有强结构 → 就利用结构（投影、对称、规则）而非暴力特征匹配

---

## 附：这套方法在象棋项目里如何串起来

```
结构先验（象棋规则）当监督           ← 概念 1
   ↓ 用「运动信号」给棋子打标
先找盲区：运动色盲 → 外观补颜色      ← 概念 2
   ↓ 用真实视频 + 规则传播自动标注
绕开域差：不训合成模型，标真实数据    ← 概念 3
   ↓ SAM 粗定位 → 网格线精修
用先验降难度：ROI + 单应 → 投影找峰  ← 概念 4
```
