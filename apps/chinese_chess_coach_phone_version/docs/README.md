```
方案v2（合成数据+全模型）
   └→ 棋盘定位探索（10-02 真机：SAM 唯一可行）→ 方向A/B（A=EdgeSAM 轻量分割）
        └→ 架构修订（10-06：YOLO 自训 + ONNX 端侧，M5-M7）
             └→ 真实数据自动标注（方法D：规则 teacher，M0-M5）
                  └→ 数据飞轮 + 回放复刻（v3→v9 模型迭代）
                       └→ 里程碑 M1（10-09 收官，见 00-现状）
```

## 维护规则

1. 日常进展追加到 `00-现状/开发日志.md`（倒序）；
2. 新的现行方案放 `01-现行设计/`，顶部写明日期与状态；
3. 方案被取代时**移入 `02-历史方案/`** 并在顶部加归档标注（指向取代者）；
4. 探索失败/死路结论记入 `03-探索与调研/`（防重走弯路，最有价值的资产之一）；
5. 里程碑节点在 `00-现状/` 写总结并更新本 README 的「当前状态」。
