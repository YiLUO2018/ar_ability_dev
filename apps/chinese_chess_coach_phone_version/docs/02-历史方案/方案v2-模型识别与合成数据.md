## 1. 目标与约束（更新）

1. **棋盘与棋子都用模型识别**（不依赖 OpenCV 经典 Hough/模板）。
2. **UI 叠加要求棋盘有明确检测**：模型必须输出**棋盘四角**（供单应矩阵 → 网格↔画面映射 → 画箭头/高亮）。
3. 模型**可自训**，或**基于已有模型（VinXiangQi/chess-dike、YOLO 预训练）用自有数据微调**。
4. **标注数据能自动化生成**：核心手段是「合成渲染」——象棋几何固定，程序化渲染即可得到天生已知的标签，无需人工标注。
5. 运行时零 GMS、本地离线推理（TFLite）。

---

## 2. 总体架构（两阶段模型）

```
相机帧 Bitmap
   │
   ├─ ① 棋盘角点模型 (BoardDetector)
   │       输出：4 角 ──► 单应矩阵 grid→image + 透视校正棋盘图 warped
   │                              ├──► 供 UI 叠加（画箭头/高亮）
   │                              └──► warped 供棋子分类
   │
   └─ ② 棋子分类模型 (PieceRecognizer, 逐格 15 类)
           输入：warped 规整棋盘
           输出：每交叉点类别 (空/红黑×7) ──► 9×10 网格
                                              ──► Board ──► 引擎 ──► Move
```

**为什么拆两阶段**：
- 棋盘角点模型输出「4 个明确角点」，是 UI 叠加的几何基础（透视下必须是 4 点，而非轴对齐框）。
- 棋子分类模型在 warped 规整棋盘上整盘分类，尺度归一化、确定性强、无 NMS。
- 两阶段各自可独立训练、替换、验证。

**运行时处理细节**（每识别帧）：
1. 角点模型输出 4 角 + 峰值置信度；峰值低于阈值 → 判「无棋盘」→ 返回 null、清空 UI。
2. 角点做帧间 EMA 平滑（抑制箭头抖动）。
3. 由 4 角求单应 → warp 到 canonical → 整盘一次前向分类 → 9×10 网格。
4. 朝向判定：按红方棋子位置判 180° 朝向，必要时翻转 grid。
5. 合法局面校验（数量/将帅/九宫/照面）；失败保留上一合法局面。
6. 局面稳定门控：连续 K 帧一致才更新 latestBoard，避免人手移动中的瞬态。

## 3. 模型选型

### 3.1 棋盘角点模型（显式 4 角）

| 方案 | 说明 | 评价 |
| :-- | :-- | :-- |
| **A. 热力图关键点 + soft-argmax/DSNT** | 骨干（MobileNetV3-Small）+ 上采样头输出 4 通道热图，soft-argmax 取亚像素角点 | ✅ 首选：精度最高、抗遮挡、子像素、时序平滑 |
| B. 直接回归 4 角 | 轻量 CNN 直接回归 8 个值 (4 点 x,y) | 备选：极简、最快，但精度/稳定性略逊、有角点顺序歧义 |
| C. 分割（UNet）+ 四边形拟合 | 分割棋盘区域 → 轮廓求 4 角 | 备选：鲁棒，但后处理繁琐、帧间拟合抖动 |

> **首选 A（热力图 + soft-argmax）**。4 个角各占一通道，无顺序歧义；soft-argmax 给亚像素坐标（UI 叠加对角点精度敏感：角点差 1~2px 会放大远端箭头抖动）。配置：输入 320×320（棋盘偏小可上调 384），骨干 MobileNetV3-Small，头 stride=4 的 4 通道热图，损失高斯热图 MSE（或 CenterNet focal loss），解码 soft-argmax/DSNT（输出归一化 [0,1] 坐标，避免多级缩放误差）；同时输出峰值置信度用于「无棋盘」判定。经典 OpenCV 仅作离线兜底。

### 3.2 棋子分类模型（逐格 15 类，整盘一次前向）

| 方案 | 说明 | 评价 |
| :-- | :-- | :-- |
| **A. 透视校正后整盘分类（15 类）** | warp 到 canonical（~450×500）→ 一次前向输出 `10×9×15` logits | ✅ 首选：尺度归一化、确定性、无 NMS、一次推理出整盘 |
| B. 逐格 crop 分类（15 类） | 每交叉点切 ROI 单独分类 | 劣于 A：90 次推理、丢上下文，仅作概念参考 |
| C. YOLO 检测（14 类）+ 网格吸附 | 原图检测 bbox → 单应映射到最近交叉点 | 备选：不依赖 warp，但需多尺度小目标 + NMS |
| D. 端到端全盘网格（单模型） | 单模型直接输出 10×9×N | 演进方向：部署简但训练重，仍需角点分支满足 UI |

> **首选 A（整盘一次前向）**。warp 把透视与尺度归一化后，用轻量 CNN 一次前向输出 `10×9×15`（每交叉点一个 15 类 logits），比「90 次逐格 crop」更快、更稳、能利用邻格上下文。对 warp 误差的鲁棒性通过「合成数据时给角点加微小抖动（模拟 warp 误差）」训练。C 作为「角点/warp 在真机不够稳」时的备选；经典模板匹配作离线兜底。

## 4. 合成数据自动标注管线（核心）

### 4.1 思路
象棋的棋盘几何、棋子字形**完全确定**（9×10 网格、7 种字形 × 红黑、固定字体）。用程序渲染，**标签天生已知**（棋盘四角、每颗棋子的 bbox/类别/网格坐标），做到「零人工标注 + 无限量」。

### 4.2 渲染器（`tools/data_gen/`，Python + OpenCV + PIL）
1. **棋盘层**：木纹/纯色背景 + 9 竖 10 横网格线 + 楚河汉界 + 九宫斜线。
2. **棋子层**：圆饼 + 汉字（红/黑），随机摆放到交叉点（合法布局或随机布局均可）。
3. **透视层**：随机单应变换（模拟拍摄距离/角度/旋转/平移）+ 交点级微扰。
4. **合成层**：随机桌面纹理背景、光照/阴影、色偏、高斯噪声、运动模糊、JPEG 压缩。
5. **标签输出（自动）**：
   - 棋盘 4 角坐标（供角点模型训练）。
   - 每交叉点类别标签（15 类，供逐格分类模型训练）；同时可输出每颗棋子 bbox/网格坐标供校验。

### 4.3 领域随机化（缩小合成→真实差距）
- 纹理/材质随机（木纹、塑料、纸质棋盘）。
- 光照：全局亮度、渐变阴影、高光、色温。
- 相机：透视角度、距离、径向镜头畸变、运动模糊、失焦。
- 后处理：噪声、JPEG、分辨率缩放。

### 4.4 真实照片的半自动标注（第二阶段，可选补强）
合成数据训练出的模型，反过来对**少量真实照片**打标（model-in-the-loop 自标注），人工只抽查/纠错，再混合微调一轮——进一步缩小 sim-to-real 差距，仍近乎零人工。

### 4.5 评估指标（训练时同步建立）
- 角点像素误差（MAE / 亚像素）。
- 逐格分类准确率（15 类）。
- 端到端局面准确率（整盘 90 点全对才算对）。
- 尽早准备少量真实照片验证集，专门测合成→真实 gap。

## 5. 训练 / 微调 / 导出

| 步骤 | 内容 |
| :-- | :-- |
| 1. 生成 | 运行渲染器，产出「合成数据集 + 标签」 |
| 2. 训练棋盘角点 | 合成数据从头训练（4 通道热图，高斯热图 MSE / CenterNet focal loss，soft-argmax 解码） |
| 3. 训练棋子分类 | 合成数据从头训练轻量分类器（整盘输入 → `10×9×15` 输出） |
| 4. 导出 | 转 TFLite（FP16 或 INT8），放 `assets/models/` |
| 5. 混合精调 | 可选：真实照片自标注后微调 |

模型产物：
- `board_corner.tflite`（角点）
- `piece_classifier.tflite`（棋子，15 类）

## 6. 与现有代码衔接

| 现有 | 变更 |
| :-- | :-- |
| `BoardDetector` 接口 | 不变；新增 `KeypointBoardDetector`（TFLite 角点，含置信度），`GridBoardDetector`（经典）降为 fallback |
| `PieceRecognizer` 接口 | 不变（`recognize(boardInfo)`）；`TFLitePieceRecognizer` 重写为整盘一次前向（`10×9×15`），`TemplatePieceRecognizer` 兜底 |

| 朝向判定 | 分类后按红方棋子位置判 180° 朝向，必要时翻转 grid（`buildBoard` 后） |
| 校验 | 合法局面校验（数量/将帅/九宫/照面）；失败保留上一合法局面 |
| 时序稳定 | 角点 EMA 平滑；局面连续 K 帧一致才更新；角点峰值低于阈值判无棋盘并清空 UI |
| 工厂 | `BoardDetectorFactory` / `PieceRecognizerFactory`：优先模型，失败降级经典 |

| 阶段 | 内容 | 交付 |

## 8. 风险与缓解

| 风险 | 缓解 |
| :-- | :-- |
| 合成→真实领域差距 | 领域随机化（含镜头畸变）+ 真实照片 model-in-the-loop 自标注微调 |
| 角点检测在极端透视/遮挡下仍可能偏移 | 热力图 + soft-argmax 已较鲁棒；再叠加多帧平滑/EMA 与历史稳定 |
| 棋盘 180° 朝向判反 → 走法画反 | 分类后按红方位置判朝向并翻转 grid |
| 无棋盘时角点幻觉 | 峰值置信度门控，低于阈值返回 null 并清空 UI |
| 逐格分类受 warp 误差影响而错格 | 亚像素角点 + 合成数据角点抖动训练 + 多帧一致性 |
| 训练环境/算力 | 模型轻量（MobileNet），CPU/单卡可训；数据合成成本极低 |
