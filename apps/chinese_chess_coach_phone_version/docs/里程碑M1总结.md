## 二、当前系统架构

```
相机帧 480×640（每 5 帧处理 1 帧）
 ├─ SegmentationBoardDetector（EdgeSAM encoder+decoder ONNX，真机 ~1s/帧）
 │   4 个掩码候选 → 面积带 [2%,35%] 预筛 → 逐候选四角提取：
 │     · 全可见路径：最大连通域→边界→凸包→贪心减点 4 顶点
 │     · 外推复原路径：贴边段剔除（角点出画面）→ 近共线链合并 → 边线延长求交
 │   → isValidQuad / 贴边校验（全可见）/ ±半幅边界（复原）
 │   → 两轮优先（先全可见后复原）+ 时间稳定性仲裁（与上一帧平均位移最小者）
 │   → 跳变闸（面积比 [0.75,1.35] + 角位移 0.22·对角线；连续 3 帧一致才放行）
 │   → 提示点回灌 → 自适应 EMA（α=clamp(d/0.08·diag, 0.15, 0.9)）
 ├─ QuadRefiner（≥12 棋子质心 RANSAC 单应精修：吸附 0.8 格/内点 0.35 格/校正钳 1.5 格）
 ├─ YoloPieceDetector（yolov8n ONNX：棋盘裁剪外扩 6% → 居中 letterbox 640 →
 │   [18,8400] 解码 → 逐 anchor argmax≥0.25 → 按类 NMS 0.45 → 置信度降序就近吸附）
 ├─ voteGrid（5 帧逐格多数投票，平票取新）→ FEN
 ├─ XQWLight（Java 移植，searchMain(64,1000ms) 红方执走）→ ChineseNotation 中文记谱
 ├─ BoardOverlayView（单应映射交叉点 + 建议箭头）
 └─ FlywheelCollector（conf<0.5 / 非法局面 / FEN 变化 → 难帧+metadata 落盘）
```

降级链：定位 Segmentation→Keypoint→Grid；识别 YOLO→TFLite 整盘→模板；引擎 XQWLight→Kotlin。
失败诊断常驻：detect 全候选被拒时每 10 次落盘帧 + 候选掩码到 `filesDir/debug/`。

## 六、关键决策与技术结论（防重走弯路）

1. **棋盘定位**：SAM 分割是唯一稳定方案；角点 ML 模型（合成→真实域差）、Hough（斜拍竖线偏 7-17°）、OCR（书法体 ~9%）均为死路。
2. **掩码选择**：按分数→选中碎块；按纯面积→选中溢出桌面掩码；正解 = 合法面积带 + 候选级校验 + **时间稳定性仲裁**（棋盘不瞬移）。提示工程救不了低对比边界溢出。
3. **角点外推复原三个必坑**：① 贴边判据用掩码**内容边界**（nw/4, nh/4，非 256 画布）；② 栅格阶梯毛刺须先 `simplifyRing`（垂距 <2.5px 贪心删点）；③ **贴边容差 ≥4px**（真实解码器掩码距内容边界内缩 1-3px）。
4. **旋转增强剂量**：非 90° 倍数改变棋盘画布占比（几何不一致）+ 17 倍稀释 → 置信度模糊假阳暴涨；0/90/180/270 四角度最优。
5. **YOLO 类别顺序陷阱**：CLASS_NAMES 车在马前，必须显式 `TYPE_ORDINALS` 映射，不能用 `PieceType.entries[c%7]`。
6. **RANSAC 退化单应**：随机全组合采样会收敛到秩 2 退化解且内点虚高 32/32；必须唯一性计分 + valid_h（投影面积下限）。
7. **180° 翻转歧义**：占位网格旋转对称无法区分，靠**墨色红度差相对判别**（每子最暗 25% 像素 R-G，红方均值应高于黑方）；绝对阈值判色在该棋盘一个像素都不过。
8. **XQWLight 崩溃坑**：根节点无合法走法时 `searchRoot` 负下标越界，桥接层必须先 `generateMoves().isEmpty()` 判空。
9. **本机 GPU 禁跑 SAM 长推理**（RTX 4060 驱动级崩溃，6 次确认）；SAM 离线标注唯一可靠 = Windows 原生 CPU（~8s/帧）。
10. **数据集切分**：必须按时间序（文件名数字序）80/20，防相邻帧泄漏（v3 教训）。
11. **自证循环防护**：飞轮 YOLO-in-the-loop 标注中 YOLO 只当提议者，规则 + 判色 + 置信度三重裁决；乱摆中局静态帧无独立身份源，标不了（需视频运动传播）。
12. **ONNX 契约**：YOLO 输出 [1,18,8400]（非 [1,8400,18]），后 14 通道已 sigmoid；EdgeSAM 预处理 resize 长边 1024 + (v-mean)/std + 右下补零。
13. **诊断钩子不能删**：saveMaskPng/saveFailDiag 类离线复现入口是定位真机问题的生命线（10-09 角出画问题即靠它定位）。
