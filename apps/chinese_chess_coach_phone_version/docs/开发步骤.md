## 2. 第一步：新建项目

1. 打开 Android Studio，欢迎界面点 **New Project**（已打开过项目则 `File → New → New Project…`）。

2. 模板选 **Empty Views Activity**（注意是 *Views*，不是 *Compose*；CameraX 的 `PreviewView` 是传统 View）。

3. 配置页填写：

| 字段 | 填写值 |
|:--|:--|
| **Name** | `chinese_chess_coach_phone_version` |
| **Package name** | `com.arability.chinese_chess_coach_phone_version` |
| **Save location** | `L:\projects\ar_ability_dev\apps\chinese_chess_coach_phone_version` |
| **Language** | `Kotlin` |
| **Minimum SDK** | `API 24: Android 7.0 (Nougat)` |
| **Build configuration language** | `Kotlin DSL`（推荐） |

4. 点 **Finish**，等待右下角 Gradle 同步完成。

### ⚠️ 关键：路径别变成双层文件夹

Android Studio 会用「Save location 的父目录 + Name」自动拼路径。填完后**必须核对**最终路径显示的是：

```
L:\projects\ar_ability_dev\apps\chinese_chess_coach_phone_version
```

而**不是**：

```
L:\projects\ar_ability_dev\apps\chinese_chess_coach_phone_version\chinese_chess_coach_phone_version
```

若出现后者，把 Save location 改为 `L:\projects\ar_ability_dev\apps`，让 Name 字段自动补上文件夹名。

> 目标目录已有 `docs/`，Android Studio 会保留它并在旁边生成项目文件，不会冲突。
