# 眼球追踪 App 设计文档

> 状态：现行基础（v0.1）｜日期：2026-10-11
> 前置阅读：`../03-探索与调研/眼球追踪技术汇总.md`（建项前全部技术调研，本文只保留现行决策与路线）。

## 1. 项目定位

- **长线目标**：眼镜式眼球追踪（近红外摄像头 + 850 nm LED + PCCR/端到端，硬件方案见技术汇总 §2）。
- **当前形态**：手机近距离拍摄眼球做**算法原型**——个人开发者可行、迭代最快的切入方式。本 App（eye_tracking_phone_version）是该原型的载体。
- **算法主线**：传统算法先行（可解释、数据需求低、易调试）→ 端到端模型跟进（鲁棒、可 glint-free）。

## 2. 原型硬件与拍摄条件（现行约定）

| 项 | 约定 |
|---|---|
| 摄像头 | **前置默认**（自拍视角近距拍眼，「前置 + 外接微距」路线），App 内可切后置（+镜子路线，画质/对焦更好） |
| 距离 | 镜头距眼 5–15 cm |
| 设置 | 手动对焦锁定；关闭美颜/人像滤镜；间接强光避免高光遮瞳 |
| 稳定性 | 手机固定（支架），1080p 60fps 或 4K 30fps |
| 标注 | 采集时同步记录注视目标位置（阶段一起采集协议） |
| glint（可选） | 镜头旁贴 850 nm IR LED + 窄带滤光片，或先借屏幕反射 |

## 3. 五阶段开发路线

| 阶段 | 内容 | 状态 |
|---|---|---|
| 一 | 数据采集与标注：5–10 段眼球视频（多注视方向/光照），PyPupilEXT / JEOresearch-EyeTracker 离线验证瞳孔检测，调拍摄条件 | 🔄 当前 |
| 二 | 传统算法跑通：瞳孔检测（阈值→Starburst→PuRe 择优）+ 椭圆拟合 + 9 点显式校准 + 多项式映射；可选 P-CR；RLS 在线更新 | ⬜ |
| 三 | 隐式校准集成：UI 点击回溯注视轨迹 + 时空过滤，持续更新校准；漂移检测（>2.0° 触发快速显式重校准） | ⬜ |
| 四 | 端到端模型：L2CS-Net / GazeTorch 类轻量模型，InvisibleEye / GazeCapture 预训练迁移，自采数据微调；对比传统路线 | ⬜ |
| 五 | 端上部署：TFLite/LiteRT 或 ONNX Runtime 实时推理，精度/鲁棒性/速度综合验证 | ⬜ |

**校准策略（贯穿）**：首次显式 9 点获得初值 → 隐式持续修正佩戴/持机滑动累积误差（0.1 mm 滑动 ≈ 1° 误差）。

## 4. App 骨架设计（已实施，2026-10-11）

```
app/src/main/java/com/arability/eye_tracking_phone_version/
├── MainActivity.kt      # 单 Activity：相机生命周期 + 帧回调桩 + 状态行
└── (gaze/ 包按阶段引入，见 §5)
```

- **单 Activity**，无 Fragment/Navigation（对齐本仓库其他 App 形态）。
- **CameraX 1.6.0**：Preview + ImageAnalysis（`STRATEGY_KEEP_ONLY_LATEST`，单线程 executor）。
- **`lensFacing` 默认前置**；切换按钮走 `hasCamera` 校验后 unbindAll → 重绑。
- **processFrame 桩**：只统计帧率/分辨率，每秒回主线程刷新状态行；阶段二在此接入 `ImageProxy → Bitmap → 瞳孔检测`。
- 日志统一 `Log.i`（设备可能过滤 DEBUG 级）。
- 依赖不含 ONNX/TFLite（阶段四/五按需引入）。

## 5. 模块规划（随阶段落地，避免过早抽象）

| 包/模块 | 引入阶段 | 职责 |
|---|---|---|
| `gaze/PupilDetector` | 二 | 瞳孔检测：阈值/Starburst 实现 + 椭圆拟合，输出中心/长短轴/置信度 |
| `gaze/GlintDetector` | 二（可选） | 角膜反射点检测（若上 IR 光源） |
| `gaze/Calibration` | 二 | 9 点显式校准 UI + 多项式拟合 |
| `gaze/GazeEstimator` | 二/三 | 特征（瞳孔坐标或 P-CR）→ 注视方向映射；RLS 在线更新 |
| `gaze/ImplicitCalibrator` | 三 | 点击回溯 + 时空过滤 + 漂移检测 |
| `gaze/nn/` | 四/五 | 端到端模型推理封装 |
| `tools/`（Python，仓库内） | 一 | 采集数据离线分析：瞳孔检测试跑、数据集转换、训练脚本 |

## 6. 数据集与外部资源（备查）

InvisibleEye（28 万+ 近距眼图，首选）/ TEyeD / OpenEDS / GazeCapture；工具链 PyPupilEXT、pupil-labs/pupil、L2CS-Net、GazeTorch、MediaPipe Face Mesh。详见技术汇总 §7。

## 7. 关键挑战跟踪

隐私（本地处理）、佩戴/持机滑动（隐式校准补偿）、个体差异 kappa 角（校准吸收）、端到端跨被试泛化（微调 + 隐式校准兜底）、隐式校准数据质量（时空过滤）。展开见技术汇总 §9。
