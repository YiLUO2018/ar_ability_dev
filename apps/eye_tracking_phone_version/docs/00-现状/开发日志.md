# 开发日志（倒序）

## 2026-10-11 阶段一：4 段素材瞳孔检测验证（经典管线跑通）

**素材**：`debug_frames/video_20261011_*.mp4` ×4（前摄 1080p@30，~30s/段，3 横 1 竖，双眼特写 20–30cm，多注视方向）。视觉评估：无严重美颜、环境反光可当天然 glint；短板=近距离对焦偏软，视频 3（竖拍）半眯眼+涂抹感最弱。

**工具**：`tools/eye_proto/pupil_detect.py`（三级管线，输出 annotated jpg + pupil.csv + 检出率）：
1. **候选**：左右半幅自适应阈值（**bs=91**，51 会把软对焦虹膜打碎）找暗团块，形状/亮环过滤后 top-4；
2. **配对**：左右候选两两组合，|Δy|<0.07H、尺寸比<2.4；
3. **瞳孔验证裁决**：每候选取瞳孔（Starburst）→ 配对排序键=(双双通过验证的瞳孔数, 候选分和)。**眉毛对形状过滤杀不死（亮环对比也高），但双双拟合不出圆瞳孔——瞳孔可分性是最好的「这是不是眼睛」判据**。

**Starburst 瞳孔提取**（阈值法失效后的正解）：bbox 全域 5% 分位暗核质心做种子 → 32 条放射线取最远强上升梯度（>8/2px）→ fitEllipse。圆度 0.11–0.29 vs 阈值法 0.3–0.8 乱跳。

**结果**（1fps 抽帧 244 帧）：
| 视频 | 瞳孔检出率 L/R | 瞳径一致性 |
|---|---|---|
| 104508 | 75% / 64% | 140±9 / 145±7 px |
| 104559 | 42% / 61% | 139±12 / 149±8 px |
| 104657（竖，半眯） | 26% / 55% | 155±3 / 152±5 px |
| 104802 | 22% / 25% | 126±4 / 135±13 px |

视觉复核：正常注视帧椭圆套准瞳孔；失败集中在**极端侧视（虹膜被内眦遮挡）+ 半眯眼 + 强窗光反光**帧。邻帧瞳心位移 33–103px（含真实眼动，此批无注视真值不可分离）。

**踩坑记录（防重走）**：
- OpenCV 5.0 移除 `CascadeClassifier`（无 Haar 级联），眼睛定位只能走几何先验/自研。
- 单帧候选的「纯暗度评分」必被头发碾压（首版锁右上角发区）；亮环对比也压不住眉毛——**双眼对称配对+瞳孔验证**才稳。
- 虹膜+眼睑阴影粘连成 ~330×116 横条是常态（aspect~2.8），形状上限收到 1.9 会全灭；放宽让瞳孔阶段裁决。
- **种子分位必须在 bbox 全域算，不能只在成分像素上算**——成分全暗 → 阈值过低 → 9px 腐蚀后薄核消失（实测 47/55 帧死种子）。
- 该设备过滤 app 级 logcat 的教训在 PC 侧同样适用：验证走落盘（annotated jpg / CSV）。

**结论（阶段一产出：拍摄条件指引）**：
1. 前摄 1080p30 可用；主限制是**近距对焦软**——采集时点击屏幕对焦到眼并锁定 AE/AF（或稍拉远至 15–20cm）。
2. 避免窗光直射产生瞳内大片反光；环境反光点小而稳定时可当天然 glint 用。
3. 首轮校准采集避免极端侧视/半眯帧；中等幅度注视扫视为主。
4. **下一批采集必须带注视真值**（屏上 9 点刺激 + 时间同步），否则只能验证「检得出」无法验证「估得准」。
