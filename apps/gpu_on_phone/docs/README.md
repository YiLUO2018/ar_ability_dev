# gpu_on_phone — 文档索引

> 探索手机端 GPU（及 NPU/DSP 等加速单元）对模型推理的利用：统一基准 → 框架/后端横评 → 沉淀可复用推理封装。
> 动机：象棋 App EdgeSAM 定位真机 CPU ~1s/次（检测率仅 ~1Hz），且眼球追踪/人脸识别后续均需端侧推理选型。
> **当前状态（2026-10-15）**：调研与方案设计完成（10-14）；**G0-2 benchmark App 骨架已建**（ORT 1.31.0，CPU/XNNPACK/NNAPI/NNAPI-fp16 四后端 + 唯一计时路径 + JSON 落盘 + 8 单测过、APK 产出）。待办：G0-1 真机摸底（getprop）、G0-3 模型拷入+测试集+golden、G0-4 精度评估器。
