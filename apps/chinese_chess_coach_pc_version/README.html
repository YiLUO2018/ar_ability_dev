象棋视频识别与走子建议系统（PC 版，chinese_chess_coach_pc_version）

建项：2026-10-16 ｜ 状态：设计阶段（方案定稿待实施） 姊妹项目：apps/chinese_chess_coach_phone_version（手机 AR 教练 App）——本项目的检测数据引擎（v10 数据集）由其「方案 A：PC 强模型自动标注（RF-DETR）」供给，跨项目复用。

定位

电脑端程序（RTX 4060 8GB）：输入象棋视频/图像 → 棋盘角点与棋子检测 → FEN 局面重建 → Pikafish 引擎分析 → Qwen 语言塔生成讲解/评论 → 全链路可视化渲染输出。

核心原则：引擎算，模型说；检测做眼睛，语言做教练。

  • 不让 VLM 下棋（象棋搜索空间 10^40+，Pikafish 每秒搜索数百万节点，模型无法匹敌且无法自我验证）
  • 局面事实永远来自结构化输出（FEN + 引擎分析），视觉 token 只负责场景语气——防幻觉是架构纪律
  • 共享视觉编码器：图像一次编码，检测分支（高频）与语言分支（低频按需）复用

架构一览

图像 → 共享视觉编码器（DINOv2 系，冻结）
         ├─ 检测分支：角点头(4kpt) + 棋子头(DETR, 14类) → 透视/网格映射 → FEN
         │                                                        ↓
         │                                              Pikafish（走法/评分/PV）
         └─ 语言分支：投影层 → 视觉 token ──────────┐
                                                    ↓
                          Qwen 2B/4B（FEN+引擎+视觉+用户问题 → 讲解/评论）
                                                    ↓
                          可视化渲染（角点框/棋盘面板/走法箭头/评分条/评论气泡）
